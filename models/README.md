# Models and training pipeline

`raksha_training/` contains the YOLOv8, OpenCV, R3D-18, evaluation and streaming code. `configs/` holds small smoke-test and full-run settings. `runs/` is the local destination for reports, caches and checkpoints and is excluded from Git. `finalize_uvh_manifest.py` verifies a completed pinned Hugging Face download; `finish_uvh_download.ps1` waits for a downloader PID, refreshes provenance, exports vehicle-box labels and prepares split-safe YOLO data only after source integrity is complete. `train_yolo_after_prepare.ps1` waits for the prepared split and a CUDA-enabled PyTorch environment, then runs YOLOv8-S training and the official UVH validation benchmark. After successful completion, it deletes only `dataset/UVH-26/`; its run metadata preserves the dataset revision, license, attribution, and model checkpoint.

For a partial-download development experiment, run `python -m models.raksha_training prepare-uvh-available --config models/configs/phase2.partial.json`, then `python -m models.raksha_training train-yolo --config models/configs/phase2.partial.json`. This configuration trains for one epoch on a 10% training fraction at 320 px and reports only its exploratory validation metrics; it has no final test split and must not be presented as final accident-detection performance.

Run commands from this project directory with `python -m models.raksha_training ...`. The JSON path settings are project-relative, so relocating the checkout does not require editing them. A model checkpoint is only produced after a corresponding training job has actually completed.
